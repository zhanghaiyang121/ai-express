## 1. 模块概述

### 1.1 技术选型
- **前端框架**: Vue 3 + TypeScript (`<script setup lang="ts">`)
- **状态管理**: Pinia (Composition API style)
- **HTTP 客户端**: Axios (封装于 `src/utils/request.ts`)
- **样式方案**: SCSS (scoped)
- **UI 模式**: 对话框弹窗表单、分页表格

### 1.2 目录结构 (规划)
```
src/
├── views/
│   └── UserManagement.vue           # 主页面 - 组合所有组件
├── components/

├── stores/
│   └── userManagement.ts            # 用户管理 Pinia Store
├── router/
│   └── index.ts                     # 修改：添加 /users 路由
└── components/
    └── Layout.vue                   # 修改：TopNav 添加导航入口
```

### M02-01 创建用户管理 Pinia Store
| 属性 | 内容 |
|------|------|
| **状态** | ✅ 已完成 |
| **文件** | `src/stores/userManagement.ts` |
| **依赖** | `userApi`, `types` |

#### State
```ts
interface UserManagementState {
  list: UserInfo[]         // 用户列表
  total: number            // 总条数
  loading: boolean         // 加载状态
  currentPage: number      // 当前页码
  pageSize: number         // 每页条数

```

#### Actions
- `fetchUserList(page?, pageSize?)` – 分页获取用户列表
- `updateUser(id, data)` – 更新用户信息
- `deleteUser(id)` – 删除用户
- `resetState()` – 重置状态

#### 职责
- 初始化加载用户列表 (`onMounted` 调用 `store.fetchUserList()`)
- 管理三个子组件的通信和状态
- 顶部包含"新建用户"按钮

  - `UserDeleteConfirm.confirm` → 执行删除并刷新

## 3. 数据流

```
UserManagement.vue (主页面 - 状态协调器)
  │
  ├─ UserTable.vue        ← props: users[], loading, total, currentPage, pageSize
  │   └─ emits: page-change(page), edit(user), delete(user)
  │
  ├─ UserFormDialog.vue   ← props: visible, user?
  │   └─ emits: close(), submit-success()
  │       └─ 内部调用 store.updateUser() / userApi
  │
  └─ UserDeleteConfirm.vue ← props: visible, user
      └─ emits: close(), confirm(user)
          └─ 父组件调用 store.deleteUser(user.id)
                    ↓
              userManagementStore (Pinia)
                    ↓
              userApi.getUserList / updateUser / deleteUser
                    ↓
              axios request.ts → Backend API
```
