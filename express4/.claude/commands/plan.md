# 制定计划 (Plan)

## 1. 概述

本命令定义了 Express4 项目中系统化的开发计划制定流程。帮助开发者将需求拆解为可执行的任务，估算工作量，设置里程碑，并形成清晰的执行路线图。

---

## 2. 触发方式

- 输入: `/plan` 或说 "制定开发计划"
- 输入: `/plan 用户管理模块` 或说 "为用户管理模块制定开发计划"

---

### 步骤 4：里程碑规划

```markdown
## 里程碑

| 里程碑 | 日期 | 交付物 | 验收标准 |
|--------|------|--------|----------|
| M1: 后端 API 完成 | YYYY-MM-DD | 完整的 CRUD API + 测试 | 所有 API 测试通过 |
| M2: 前端页面完成 | YYYY-MM-DD | 用户列表页面 | 页面功能验收通过 |
| M3: 集成测试 | YYYY-MM-DD | 测试报告 | 核心流程无阻塞 Bug |
| M4: 上线 | YYYY-MM-DD | 生产环境部署 | 监控指标正常 |
```

### 步骤 5：风险识别

```markdown
## 风险与应对

| 风险 | 概率 | 影响 | 应对措施 |
|------|------|------|----------|
| 第三方依赖升级导致兼容性问题 | 中 | 高 | 锁定版本，逐步升级 |
| 性能不达标 | 低 | 中 | 提前做性能测试，预留优化时间 |
| 需求变更 | 中 | 中 | 优先级排序，低优先级可延期 |
| 人员变动 | 低 | 高 | 文档完善，代码规范统一 |
```

## 5. 快速启动

### 简单模块
> "/plan 用户管理模块"

AI 助手将快速生成包含路由、控制器、服务、页面的标准 CRUD 模块计划。

### 复杂项目
> "/plan 电商后台管理系统"

AI 助手将先进行需求分析，拆解为多个模块，再为每个模块制定详细计划。

---

## 6. AI 助手执行流程

当用户触发此命令时，AI 助手将：
1. 了解需求范围和优先级
2. 设计技术方案和数据模型
3. 将需求拆解为可执行的任务列表
4. 估算每个任务的工作量
5. 规划迭代和里程碑
6. 识别潜在风险
7. 生成完整的开发计划文档
8. 输出可直接使用的任务清单

---

## 7. 检查清单

计划完成前确认：
- [ ] 需求已明确，P0/P1/P2 优先级已划分
- [ ] 技术方案已确定，与现有架构兼容
- [ ] 任务拆解粒度合理（每个任务 0.5d ~ 2d）
- [ ] 工作量估算合理（考虑测试、联调、文档时间）
- [ ] 里程碑和验收标准清晰可衡量
- [ ] 风险有识别和应对措施
- [ ] 依赖项已明确（人员、接口、环境）
