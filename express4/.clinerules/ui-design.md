通用B端后台系统UI设计规范（企业级通用标准）
1. 概述
1.1 适用范围
本规范为通用企业级B端后台UI统一标准，无业务绑定、无项目专属定制，适用于所有前后端分离中后台系统，涵盖Vue、React等技术栈，可作为团队统一落地基准规范。
适用场景：权限管理、数据中台、运维后台、项目管理、OA、CRM、ERP、各类业务管理系统。
1.2 设计风格定位
整体风格：极简扁平化、轻量化商务风、高信息密度、低视觉干扰、状态可视化、层级清晰、适配长期迭代。
摒弃冗余装饰，以业务效率、数据可读性、界面统一性为核心，适配多人协作开发、长期迭代维护。
1.3 核心设计原则
- 信息优先：弱化视觉装饰，突出业务数据与操作入口，保证高效办公体验
- 状态可视化：通过标准化色彩、标签、图标区分业务状态、优先级、数据类型
- 全局统一：圆角、间距、色值、字体、交互、组件样式全项目统一
- 层级分明：背景、文字、边框、阴影、弹窗严格分层，杜绝视觉混乱
- 高复用性：所有组件标准化、通用化，避免个性化散乱样式
2. 全局布局规范
2.1 标准全局布局结构
所有后台系统统一采用经典三栏固定布局，全局结构统一，禁止自定义差异化布局：
- 左侧侧边导航栏：固定宽度，承载系统菜单、路由导航、功能模块入口
- 顶部全局 Header：通栏置顶，承载系统名称、功能入口、消息通知、用户信息、系统设置
- 右侧主内容区：核心业务展示区域，包含页面标题、筛选栏、表单、表格、弹窗等
2.2 固定布局尺寸
- 侧边栏固定宽度：240px（折叠状态自适应收缩）
- 顶部栏固定高度：60px
- 主内容区内边距：24px
- 通用卡片内边距：16px / 24px
2.3 栅格间距系统（全局强制统一）
全局采用8px 倍数栅格体系，所有内外边距、模块间距必须遵循该规则，禁止自定义任意像素值：
- 基础最小间距：8px
- 常规模块间距：16px
- 大块区域间距：24px
- 页面模块分隔间距：32px
3. 全局色彩系统
所有颜色全局统一变量化，禁止页面硬写色值，严格区分中性色、主题色、状态色、标签色，适配所有B端业务场景。

- 系统主主题色：#165DFF（通用商务蓝，全站统一品牌色）

- 文字按钮：主题色文字，无背景无边框，hover 轻微变色
4. 字体排版规范

font-family: -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "Helvetica Neue", sans-serif;

5. 通用组件UI规范
5.1 侧边导航菜单
- 一级菜单：标配图标+文字，支持折叠展开
- 二级子菜单：左侧缩进，层级清晰
- 激活状态：主题色文字 + 左侧主题色标识条 + 浅底色高亮
- hover 状态：全局浅底色过渡，无突兀样式
5.2 顶部筛选工具栏
- 统一控件高度：36px
- 布局规范：左侧筛选控件、中间搜索框、右侧操作按钮
- 所有输入框、下拉框样式统一，圆角一致
- 主功能按钮固定放置工具栏最右侧
5.3 Tabs标签页
- 默认未激活：辅助色文字，无下划线
- 激活状态：重点色文字 + 底部 2px 主题色实线
- 切换过渡平滑，无闪烁、无突兀样式变化
5.4 数据表格通用规范
- 表头：加粗重点文字，纯白底色
- 表格行高统一：48px
- 行悬浮高亮：浅底色 hover 效果
- 状态展示：小圆点状态标识+状态文字
- 优先级/类型展示：圆角小标签统一样式
- 操作列固定居右，统一图标按钮样式
5.5 卡片模块规范
- 统一圆角、浅边框、纯白底色
- 摒弃厚重阴影、渐变、冗余装饰
- 内边距统一规范，模块间距遵循8px栅格
5.6 弹窗/下拉/气泡组件
- 底色纯白，柔和浅阴影，无硬边框
- 统一圆角规范，视觉轻量化
- 弹出/关闭淡入淡出平滑过渡
6. 全局控件与交互规范
6.1 圆角统一标准（全站强制）
- 小型控件（按钮、输入框、下拉、标签）：6px
- 大型模块（卡片、弹窗、菜单面板）：8px
6.2 图标规范
- 统一使用线性2px简约线条图标
- 常规图标尺寸：16px / 18px
- 全站图标风格统一，禁止混搭面性、彩色、粗线条图标
6.3 统一Hover交互规则
- 主按钮：hover 加深主题色
- 次要控件：hover 唤起主题色边框/文字
- 表格行、菜单选项：hover 浅底色高亮
6.4 全局过渡动画
所有交互样式变化统一启用平滑过渡，杜绝生硬切换：
transition: all 0.15s ease-in-out;
7. 全局CSS变量（可直接落地项目）
所有样式统一使用变量，禁止页面硬编码色值、尺寸，方便全局统一迭代换肤、改版。
:root {
  /* 中性色 */
  --color-bg: #ffffff;
  --color-bg-sidebar: #f5f7fc;
  --color-bg-hover: #fafbff;

  --text-primary: #1d2129;
  --text-normal: #4e5969;
  --text-placeholder: #86909c;

  --border-color: #e5e7eb;

  /* 主题色 */
  --color-primary: #165DFF;

  /* 业务状态色 */
  --status-wait: #c9cdd6;
  --status-running: #4086f4;
  --status-success: #36c777;
  --status-error: #ed4b4b;
  --status-warning: #ffaa33;

  /* 优先级标签色 */
  --p-high: #f53f3f;
  --p-medium: #ffaa33;
  --p-low: #00b42a;

  /* 圆角规范 */
  --radius-sm: 6px;
  --radius-base: 8px;

  /* 基础间距 */
  --gap: 8px;
}
8. 整体视觉规范总结
本规范为通用无业务绑定B端后台UI标准，适配99%企业中后台系统，风格极简商务、克制统一、高适配、高可维护。所有样式规则标准化、变量化、通用化，完全适配团队多人协作、长期迭代，可直接作为项目初始化UI基线规范落地使用。
