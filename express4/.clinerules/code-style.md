# 【最高优先级·强制红线】生成代码必须严格遵守，违规立刻重做
1. TS/JS **严禁使用 var**，变量仅允许 const / let；优先 const，可变变量使用 let
2. 禁止滥用 any；类型未知优先使用 unknown，必须补齐完整类型注解
3. 缩进固定2空格，禁用tab；语句强制加分号；字符串默认单引号
4. 单行代码长度≤120字符；文件末尾保留空行、清除行尾多余空格
5. 所有公共函数、接口必须编写JSDoc注释
6. 导入顺序严格：内置模块 → 第三方包 → 项目内部文件 → 类型导入，分组空行隔开

# 代码风格规范 (Code‑Style)
## 1. 概述
本规范约束项目全部 JavaScript / TypeScript 前后端代码，统一编码风格、命名、目录结构、Git提交规范，AI生成代码全程强制执行所有条款。

## 2. 通用基础规范
### 2.1 缩进、空格与换行
1. 缩进：**2个空格**，禁止 Tab
2. 每行最大长度：120字符
3. 文件末尾保留1处空行
4. 清除所有行尾多余空白字符

### 2.2 文件编码与换行符
- 全部源码文件编码：UTF‑8
- 换行符统一 LF，禁用 CRLF

### 2.3 语句分号
- 每一条执行语句末尾强制书写 `;`
- 禁止依靠JS自动分号(ASI)运行代码

### 2.4 引号规则
1. 普通字符串优先**单引号 ' '**
2. 字符串内部含有单引号时改用双引号
3. 模板字符串 `` ` ` `` 只允许用于变量插值、多行字符串场景
