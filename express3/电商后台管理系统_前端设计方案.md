# 电商后台管理系统 - 前端设计方案

## 一、项目概述

### 1.1 业务场景
**电商平台后台管理系统** —— 面向中小型电商的全流程管理，覆盖商品、订单、用户、营销、财务、内容、权限等核心模块。

### 1.2 技术栈
- **框架**: Vue 3 + TypeScript + Composition API
- **UI 组件库**: Element Plus
- **状态管理**: Pinia
- **路由**: Vue Router 4
- **请求**: Axios + 请求拦截器
- **图表**: ECharts 5
- **构建**: Vite
- **代码规范**: ESLint + Prettier

### 1.3 设计原则
- 清晰的层级结构，操作路径最短化
- 统一的设计语言和交互规范
- 高频操作一步到达，低频操作两步内完成
- 数据可视化优先，减少纯文本展示

### 4.2 色彩规范

| 用途 | 色值 | 说明 |
|------|------|------|
| 主色 | #409EFF | Element Plus 蓝 |
| 成功 | #67C23A | 上架、已完成 |

### 4.3 交互规范

- **表格**：默认每页20条，支持50/100切换；斑马纹；hover高亮
- **筛选**：常用筛选项直接展示，高级筛选折叠；筛选结果实时刷新
- **表单**：必填项标红星；实时校验；长表单分步或分区块
- **操作反馈**：成功/失败用 Notification；危险操作二次确认；加载态骨架屏
- **空状态**：无数据时展示插画 + 引导文案
- **权限控制**：按钮级权限，无权限按钮隐藏或置灰

### 5.2 权限方案

```
登录 → 获取用户信息 + 权限列表
     → 动态生成路由（addRoute）
     → 侧栏菜单动态渲染
     → 按钮级权限指令 v-permission
```

- **路由权限**：后端返回权限码 → 前端过滤路由 → addRoute 动态注册
- **按钮权限**：v-permission="'goods:publish'" 指令控制按钮显隐
- **页面权限**：无权限页面自动跳转403

### 5.3 请求封装

- 统一请求拦截：自动携带 Token、请求头
- 统一响应拦截：错误码处理、Token过期刷新、统一错误提示
- 请求取消：路由切换取消未完成请求
- 重复请求拦截：同一接口短时间重复调用自动取消
