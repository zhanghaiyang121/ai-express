## P0：基础架构（12项）

| # | 任务 | 说明 | 优先级 |
|---|------|------|--------|
| 01 | Vite + Vue3 + TS 项目初始化 | 脚手架搭建，配置 alias、环境变量 | P0 |
| 02 | Element Plus 按需引入配置 | unplugin-vue-components + unplugin-auto-import | P0 |
| 03 | 全局样式体系搭建 | variables.scss、reset.scss、element 主题覆盖 | P0 |
| 04 | Axios 请求封装 | 拦截器、Token管理、错误处理、重复请求取消、请求取消 | P0 |
| 05 | 路由基础配置 | Vue Router 4 初始化、路由守卫、NProgress 进度条 | P0 |
| 06 | Pinia 状态管理 | user/app/permission 三个 store 定义 | P0 |
| 07 | 动态路由与权限方案 | 后端权限码 → 过滤路由 → addRoute 动态注册 | P0 |
| 08 | v-permission 按钮权限指令 | 按钮级权限控制 | P0 |
| 09 | 布局组件开发 | Layout 主框架（Sidebar + Header + MainContent） | P0 |
| 10 | 侧栏导航组件 | 可收起、多级菜单、路由联动高亮 | P0 |
| 11 | 顶部栏组件 | LOGO、全局搜索、消息通知、用户头像下拉 | P0 |
| 12 | 登录页 + 忘记密码页 | 表单校验、Token存储、登录跳转 | P0 |
